# MFA / Conditional Access

Goal: converge fragmented legacy Conditional Access into a controlled global baseline.

## Design principles

- All Users baseline where appropriate
- Report-only before enforcement
- controlled pilots and waves
- explicit exception ownership, justification and review date
- no automatic inheritance of legacy exclusions
- keep emergency access separately governed
- classify non-human identities before enforcement

Never disable a legacy policy until the replacement is validated and rollback is documented.

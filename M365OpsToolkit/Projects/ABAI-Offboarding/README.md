# ABAI Offboarding

Purpose: support a controlled post-acquisition separation from the Atento tenant.

## Current operating principle

No destructive action until a formal GO decision is recorded.

## Minimum checklist

- identities and synchronized objects
- group memberships and privileged roles
- recent sign-ins / MFA dependencies
- directory synchronization dependencies
- cross-company tunnels and VPN dependencies
- Azure identity/access dependencies
- SharePoint sites and regulatory backup requirements
- Defender/device dependencies
- owners for every unresolved item
- rollback/recovery path
- post-removal validation

Use read-only inventory first. Do not turn dependency discovery into remediation ownership for the other organization.
